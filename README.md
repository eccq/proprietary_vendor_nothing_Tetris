# Proprietary vendor files for CMF Phone 1

Proprietary blobs and firmware for the CMF Phone 1 ("Tetris"), used to
build DescartesOS (based on LineageOS 24 , Android 17).

All files are from CMF Phone (1) stock firmware `Tetris_B4.1-260928-1140`,
unless noted otherwise in `device/nothing/Tetris/proprietary-files.txt`.

The makefiles are generated by `device/nothing/Tetris/setup-makefiles.py`. Do not
edit `Android.bp` or `tetris-vendor.mk` by hand. Large files are stored with
Git LFS, so run `git lfs install` before cloning.

The proprietary files belong to Nothing Technology Limited and their respective
owners.
